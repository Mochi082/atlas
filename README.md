# ATLAS COMPUTER Webサイト改修改善

株式会社アトラスコンピュータのWebサイトを対象に、既存サイトの情報整理・UI/UX改善・デザイン改修を行うインターン制作プロジェクトです。

## 目的

既存サイトの情報や導線を整理し、ユーザーが目的の情報へアクセスしやすいWebサイトへの改善を目指します。

主な改善対象：

- 情報設計・ページ構成の整理
- ページ間の導線改善
- UI / UXの改善
- デザイン・レイアウトの改善
- レスポンシブ対応
- お問い合わせフォームの改善
- コードの保守性向上

## 開発方針

各担当者がそれぞれのページを個別に制作します。

制作途中では無理にデザインを統一せず、各ページの目的に適した情報構成・UIを検討しながら開発を進めます。

全6ページの制作後、一度統合用ブランチにすべてのページを統合し、サイト全体を確認した上でデザインやコードを調整します。

最終統合時には、サイト全体のデザイン、ヘッダー・フッター、CSS / JavaScript、ファイル構成・参照パス、レスポンシブ対応、ページ間の導線、UI / UX、重複・不要コードなどを確認します。

最終確認後に `main` ブランチへ統合します。

## ブランチ運用

`main` へ直接変更を加えず、各作業ブランチで制作を進め、Pull Requestで差分を確認します。

例：

- `feature/company-page`
- `feature/partner-page`
- `feature/contact-page`
- `feature/member-pages`
